Module 01 — Prompting

The Art of Prompting

Every AI interaction starts with a prompt. The difference between generic output and exceptional results? How you write it. This module teaches you a repeatable framework for writing clear, structured prompts that work across any AI tool.

◆ Core Framework
The 5-Layer Prompt Architecture

Every great prompt contains five layers of information. Think of it like writing a brief for a specialist — the more precise your instructions, the better the result.

✕ Common Mistake
The Vague Prompt

Most people write prompts like text messages — short, vague, and hoping the AI reads their mind. It doesn't.

Weak Prompt
Write me a summary of this report
✓ Professional Result
The Layered Prompt

A well-crafted prompt gives the AI a complete brief. Every detail you add eliminates a decision the AI would otherwise guess on.

Strong Prompt
Act as a senior healthcare analyst. I have a 40-page quarterly report on member engagement. Summarize the top 5 findings in bullet points, prioritized by business impact. Use plain language suitable for a C-suite audience. Keep it under 200 words.
