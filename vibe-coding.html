Module 03 — Vibe Coding

Building Software Without Code

The barrier between "idea" and "working software" has collapsed. Today, you can describe what you want in plain English and watch AI build it. This is vibe coding — and it changes who gets to be a builder.

Key Concept

What is Vibe Coding?

Vibe coding is the practice of building software by describing what you want in natural language — and letting AI generate the code. You don't need to understand programming syntax, frameworks, or databases. You need to understand the problem you're solving and be able to describe the experience you want clearly.

Think of it as the difference between being an architect and a bricklayer. You design the building — AI lays the bricks. The skill shifts from writing code to thinking clearly about what software should do.

Real Possibilities

What You Can Build

  • ✓ Internal dashboards that visualize your department's data
  • ✓ Workflow tools that automate repetitive manual tasks
  • ✓ Report generators that pull from existing data sources
  • ✓ Scheduling and staffing calculators
  • ✓ Patient feedback trackers and survey tools
  • ✓ Training material generators and quizzes
Realistic Expectations

What It's NOT

  • × A replacement for enterprise software engineering
  • × Suitable for HIPAA-regulated patient data systems (without proper review)
  • × A way to bypass your IT department's security policies
  • × Perfect on the first try — iteration is always required
  • × Capable of building complex integrations without technical guidance
Framework

How to Vibe Code Effectively

  1. Start with the Problem, Not the Solution

    Before you describe what to build, articulate the problem you're solving. "My charge nurses spend 45 minutes per shift manually checking staffing ratios" is a much better starting point than "Build me a staffing app."

  2. Describe the User Experience

    Think about who will use this tool and what they need to see. Describe the screen layout, the data displayed, and the actions a user should be able to take. Be specific: "A bar chart showing each department's staffing percentage, color-coded green/yellow/red."

  3. Start Small, Then Iterate

    Don't try to describe the entire application in one prompt. Start with the core screen. Get that working. Then add features one at a time. Each iteration should be a clear, focused addition.

  4. Test Like a User, Not a Developer

    When reviewing what AI builds, don't look at the code. Click through it like a nurse, administrator, or physician would. Does it make sense? Can you accomplish the task in under 30 seconds? If not, describe what's confusing and iterate.

Example Prompt

Staffing Dashboard — A Real Prompt

Here's what a well-structured vibe coding prompt looks like. Notice how it describes the problem, the user, the layout, and the data — all without mentioning a single programming language.

Vibe Coding Prompt
Build me a staffing dashboard for a hospital nursing supervisor.

The dashboard should show 6 departments (ICU, Emergency, Medical-Surgical, Labor & Delivery, Pediatrics, Oncology) with horizontal bar charts showing current staffing percentage.

Color-code the bars: green if above 95%, yellow if 80-95%, red if below 80%.

Add a date picker at the top so supervisors can view historical data. Include a "Download PDF" button in the top-right corner for shift reports.

The design should be clean and scannable — a supervisor should be able to assess the entire floor's staffing status in under 5 seconds.

"The best software is built by people who understand the problem deeply — not necessarily people who understand code."
